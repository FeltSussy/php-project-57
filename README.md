# Task Manager

A simple task management application built with Laravel.

Users can create and manage tasks, task statuses, and labels. Tasks can be assigned to users, filtered by different parameters, and organized using labels.

## Features

- User authentication
- Task management
- Task status management
- Labels
- Task assignment
- Task filtering
- Authorization policies
- Localization
- Pagination

## Requirements

- PHP
- Composer
- Node.js
- npm
- database (e.g. PostgreSQL)

## Installation

Install PHP dependencies:

```bash
make setup
```
